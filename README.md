# JobPilot

JobPilot is a focused JavaScript project that helps organize and manage the job search process. It addresses the common problem of scattered applications, inconsistent tracking, and lost context when applying for roles.

## What problem this solves

Searching for jobs and managing multiple applications quickly becomes chaotic: tracking where you applied, which version of your resume you used, interview schedules, and follow-ups is time-consuming and error-prone. JobPilot centralizes the information that matters during a job search so you spend less time managing the process and more time preparing for opportunities.

## How it helps

- Centralized application tracking: keep application records and statuses in one place so progress is clear at a glance.
- Clear pipeline and status stages: see which applications need attention (e.g., follow-up, interview prep) and which are complete.
- Document organization: associate resumes, cover letters, and notes with each application to avoid confusion over versions.
- Prioritization and insights: simple metrics help identify high-value opportunities and where to focus effort.
- Smoother preparation: having interview details and notes in the same place reduces context switching and improves readiness.

## Key features

- Application dashboard with status tracking
- Per-application notes and document attachments
- Timeline of interactions and interview events
- Simple prioritization and summary metrics
